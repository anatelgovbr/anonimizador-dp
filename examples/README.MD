# Notebooks de Exemplo

Pasta contendo notebooks Jupyter demonstrando o uso do SEI Anonimizar em diferentes cenários.

## Notebooks Disponíveis

### 1. [exemplo.ipynb](exemplo.ipynb)

Demonstração básica das funcionalidades principais:

- Carga e processamento de texto individual
- Detecção de entidades sensíveis
- Anonimização básica
- Visualização dos resultados

### 2. [exemplo_em_lote.ipynb](exemplo_em_lote.ipynb)

Exemplo avançado para processamento em lote:

- Processamento de múltiplos documentos
- Configuração de padrões personalizados
- Exportação de resultados estruturados

### 2. [exemplo_em_completo.ipynb](exemplo_completo.ipynb)

Exemplo completo de pipeline de treino, validacao, e uso.
